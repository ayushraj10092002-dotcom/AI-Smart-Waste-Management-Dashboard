# AI Smart Waste Management Dashboard

An AI-powered Smart Waste Management Dashboard built using Flask, HTML, CSS, JavaScript, and Chart.js.

## Features

- AI Smart Dashboard
- Weekly Waste Data Table
- AI Waste Prediction
- Waste Trend Analysis
- Waste Distribution Pie Chart
- Recycling Progress
- Live Date & Time
- Download Report
- Responsive Design

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Chart.js
