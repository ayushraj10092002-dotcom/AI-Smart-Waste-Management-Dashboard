# WasteWise API

The operational API is versioned under `/api/v1`. The older `/api/...` endpoints remain available for the existing dashboard and now require an authenticated account with the corresponding organization permission.

## Authentication and CSRF

Browser and first-party API access uses the Flask-Login session cookie. Sign in with `POST /login`; signing out is `POST /logout`. State-changing session-authenticated requests require a CSRF token. Fetch one with authenticated `GET /api/v1/csrf`, then send it in the `X-CSRFToken` header. HTML forms use hidden CSRF fields.

Device telemetry is the exception: `POST /api/v1/bins/{bin_id}/telemetry` uses an organization-scoped bearer token generated by the `create-device-token` CLI command. Store the token in the device's secret store; it is displayed only once. Telemetry is never accepted without a valid token. The current demo bins remain marked simulated until a token-authenticated reading updates one.

## Response and error conventions

Successful reads return JSON unless the endpoint is an export. Writes return the created/updated resource or a small status object. Common errors use HTTP 400 for malformed requests, 401 for missing/invalid authentication, 403 for insufficient role access, 404 for missing or cross-organization resources, 409 for conflicts, 413 for requests larger than 2 MB, and 422 for validated input errors. Errors contain a short `error` message and do not include stack traces.

## Endpoints

| Method | Path | Access | Purpose |
| --- | --- | --- | --- |
| GET | `/health` | Public | Liveness status only |
| GET | `/api/v1/csrf` | Signed in | Session-bound CSRF token |
| GET | `/api/v1/analytics` | Analytics permission | Current organization's active CSV dataset; values are canonical kg |
| GET | `/api/v1/data/export.csv` | Reports permission | Export current organization's active dataset |
| GET | `/api/v1/data/export.json` | Reports permission | Export current organization's active dataset |
| PATCH | `/api/v1/organization/preferences` | Admin | Set language, mass unit, unit system, IANA timezone, date format, and currency code |
| GET | `/api/v1/tasks` | Admin, Manager, Staff | List organization tasks; Staff see assigned tasks only |
| POST | `/api/v1/tasks` | Admin, Manager | Create an organization-scoped collection task |
| PATCH | `/api/v1/tasks/{task_id}` | Admin, Manager, assigned Staff | Update task status |
| GET | `/api/v1/alerts` | Admin, Manager, Staff | List organization alerts; Staff see assigned alerts only |
| POST | `/api/v1/alerts` | Admin, Manager | Create a structured operational alert |
| PATCH | `/api/v1/alerts/{alert_id}` | Admin, Manager, assigned Staff | Acknowledge, resolve, or dismiss an alert |
| POST | `/api/v1/locations` | Admin | Create an organization location |
| PATCH | `/api/v1/locations/{location_id}` | Admin | Update or deactivate an organization location |
| POST | `/api/v1/bins` | Admin | Register an organization bin without claiming live telemetry |
| POST | `/api/v1/bins/{bin_id}/telemetry` | Device bearer token | Ingest validated fill, battery, and temperature readings |
| PATCH | `/api/v1/users/{user_id}` | Admin | Change role or active state in the same organization |
| DELETE | `/api/v1/users/{user_id}` | Admin | Delete a same-organization account, subject to last-admin protections |

Admin HTML surfaces are `/admin/users` and `/admin/audit`; they are not primary navbar items.

## Telemetry request

```json
{
  "fill_level": 74.5,
  "battery_level": 88,
  "temperature_c": 21.3
}
```

`fill_level` is required and must be between 0 and 100. Battery percentage and temperature are optional and range-validated. The device credential determines the organization; callers cannot select an organization in the payload.

## CSV import

The compatible `POST /api/import-csv` endpoint requires an Admin or Manager session, CSRF validation, a `.csv` filename, and a request no larger than 2 MB. The CSV must contain `Day` and `Waste_kg`; day labels must be non-empty and unique within the import, and waste values must be finite and non-negative. A successful import becomes that organization's active dataset. Stored values and exports are kilograms regardless of display preferences.

## Roles

- Admin: organization users, locations, bins, reports, preferences, and audit log.
- Manager: analytics, alerts, and collection planning/workflows.
- Staff: assigned bins, locations, collection tasks, and alerts.
- Student/User: classification/disposal guidance.
- Viewer: read-only dashboard, analytics, locations, bins, and reports.

All resource lookups are constrained by the signed-in organization's ID. Staff task/alert lookups also require assignment to that user.
